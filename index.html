About

I'm an ecologist and programmer at the Harte Research Institute, where I build software that helps scientists and managers analyze, explore, and visualize data. I enjoy using R, Python and occasionally C++ to solve data science problems.

I'm also an expert in firefly identification (weird flex I know). I spend my summer evenings observing fireflies and searching for rare or even undescribed species.

Software

  • Growing Degree Day Calculator: a Shiny app built with Python to help researchers estimate plant and insect emergence
  • ncview: a Shiny app built with R to visualize gridded NetCDF files
  • Alligator Production Suitability Model: R scripts to effeciently run an ecological model for American alligators in the Everglades
  • Days Since Dry Calculator: An effecient R method for calculating days since dry for large NetCDF files containing depth data
